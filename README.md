# Pulse

Pulse is a real-time multiplayer trivia game where players can create games, join with a game code, and compete by answering questions.

## Features

- Create and join multiplayer games
- Real-time player and score updates
- Randomized trivia questions
- Automatic question progression and game completion

## Tech Stack

- **Backend:** C#, .NET 10, ASP.NET Core Minimal APIs
- **Frontend:** Next.js, JavaScript, Tailwind CSS
- **Real-time:** SignalR
- **Deployment:** Azure App Service, Vercel
